## Purpose
This artifact will run Shellcode in a hollowed process. 
Which is basically create a new process, suspended, overright the EP with our shellcode, resume the process.


## Prerequisites
You should be able to run an executable on the target system.


## How to use:
- Run `sc-hollow` on the target system.
- `office_run_PE.docm` is a great way to do this from phishing.
